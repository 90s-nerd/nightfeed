Connect an external agent with MCP

MCP works independently of the built-in AI connection. It provides feed setup, previews, edits, internal search and help. It does not open the safe browser.

In your agent, choose Streamable HTTP and use:

{{ request.host_url.rstrip('/') }}/mcp

Create a dedicated API key with MCP read. Add MCP write to create/edit feeds, Refresh feeds to request refreshes, or MCP settings for non-secret global app settings.

Configure the header Authorization: Bearer YOUR_KEY. Use HTTPS outside your trusted local network. Clients must support custom Bearer headers; OAuth discovery is not provided.

Manage API keys

Feed restrictions apply to MCP reads and writes. Creating feeds and inspecting arbitrary source pages require unrestricted feed access. Global settings cannot be used with feed restrictions. Your external agent should ask for approval before calling apply_draft.
